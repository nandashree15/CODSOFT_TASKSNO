# CodSoft AI Internship - Task 1

## Educational Rule-Based Chatbot

An intelligent rule-based educational chatbot developed as part of the CodSoft AI Internship.

The chatbot can answer predefined questions related to:

- Artificial Intelligence
- Machine Learning
- Deep Learning
- Python
- Database and DBMS
- Computer Science
- Algorithms

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Features

- Interactive chatbot interface
- Rule-based responses
- Educational questions and answers
- Topic-based suggestions
- Simple and user-friendly interface
- Web-based chatbot using Flask
